were generated by the rule set of the same number. V2 and V7 left no trace in the code.

How to read a rule: for base length *b*, the start point is (100, 100) and the end point (100 + *b*, 100); the middle
point moves on a 0.5 px grid within ±4 px of the base segment (see `SyntheticDataFactory.Create`). `dx1` is the
middle point's x offset from the start point, `dx2` its x offset from the end point, `dy` its vertical offset.
A rule `|dy|: [a, b]` means the middle point is labelled *removed* when `|dy|` equals the given value and
`dx1 >= a` and `dx2 <= b`; every other cell is *retained*. `(off)` marks a rule that was present but commented out
in that version. A base length that is listed here but not in `CreateAll()` of that version was defined but unused;
the active `CreateAll()` of V23 uses base lengths 0.5, 1, 2, 4, 8, 16 and 32 px (4,182 records, 3,452 retained).
V23 has no `|dy| = 0` rule for the 0.5 px base, so its 18 collinear triads are labelled retained.
