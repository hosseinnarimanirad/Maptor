# Research-code cleanup (2026-09-26)

What changed in the simplification research code and why, as a companion to
[`logistic-regression-status-2026-09-17.md`](logistic-regression-status-2026-09-17.md). Decisions taken by
Hossein on 2026-09-26: clean the research projects and the synthetic-data file but keep every algorithm in
`Simplifications.cs`; fix the defects of the LRS comparison driver even though its numbers change (the LRS
paper is under revision); keep the hard-coded `E:\University.Ph.D` paths; no new experiments in this pass.

## Verified before changing anything

- **CTR as published = variant 1.** `SimplificationType.CumulativeTriangleRoutine` dispatches to
  `SimplifyByCumulativeTriangleRoutine` (retain the middle point, restart the window at it). Re-running the
  ISPRS experiment on building features reproduces all 21 sampled compression values of the published run
  `5. ISPRS Conf Paper\AlgorithmRun\2025-05-25-fix colors` exactly (VW, RDP and NOPW too). The paper's
  pseudo-code describes `SimplifyByCumulativeTriangleRoutine2` (retain middle and last, restart at last),
  which was never dispatched and matches 4 of 21. Both are kept; the tests in
  `tests/IRI.Maptor.Tests/Spatial/CumulativeTriangleRoutineTest.cs` pin them down.
- The JSS paper cites `github.com/hosseinnarimanirad/Maptor/tree/master/research/IRI.Maptor.Res.TrajectoryCompression`;
  research folder names are therefore fixed.
- The LRS traversal in the library equals the paper's pseudo-code (test `Simplify_MatchesThePseudoCodeOfThePaper`).

## Removed

- `SyntheticDataFactory.cs`: the 1,160 commented lines of label rules V1–V22. Their content is in
  [`synthetic-label-rule-history.md`](synthetic-label-rule-history.md); the data of every version is still in
  `4. Paper2\Model\TrainingData-vN.sdjson`.
- `LRHelper.cs` (1,489 lines): the five drivers superseded by the October 2024 campaign
  (`CompareLayers`, `CompareLayersMultiScale` "Goodv1", `CompareLayersPyramidByFixScreen` "Goodv2",
  `CompareSingleFeature`, and the commented threshold lists) and the commented model-path history. The kept
  drivers are one class each under `Common/Experiments/`, listed in the project README with the run folder
  each one reproduces, selected through `LRHelper.GeneralTest(LrsExperiment)`. Output now goes to a new dated
  folder under `AlgorithmRun` so published run folders are never written into.
- `IRI.Maptor.Res.TrajectoryCompression`: `TestThresholdChangesAlgo` (the 2022 review-paper run with 15
  methods), `LogStructure.cs`, `GeneralHelper.cs`, `AreaStatisticsHelper.cs` (2019 paths), the
  presenter's commands and the commented `AnalyzeSingleFeatureStats`/`Print`/`Save` blocks.
- `IRI.Maptor.Res.FastSimplification`: `Model/Log.cs` (header written, never a row).
- Library: `LRSampleTrainingData.cs` (fully commented file), `SyntheticDataItem.CreatePolar` (returned null),
  the two private unused Fisher-information methods of `LogisticRegression`, commented debris in
  `LogisticSimplification` and the ML `GeometryExtensions`.

Kept on purpose: every algorithm in `Simplifications.cs` (including the unpublished variants), the two
O(n) LRS variants (candidates for the traversal ablation the LRS reviewer asked for), the 13 candidate
features including dX/dY, the `probe/` and `phase-c/` harnesses.
