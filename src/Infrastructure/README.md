# IRI.Maptor.Infrastructure

The **Ket** tier connects the core [Sta libraries](../Core/README.md) to real data stores and platform services. Most projects implement the data-source abstractions from `IRI.Maptor.Core.Persistence` (such as `IVectorDataSource`), so a map layer can be backed by SQL Server, PostgreSQL, SQLite, a personal geodatabase, or a web API without changing application code. Every project is published to [NuGet](https://www.nuget.org/packages?q=IRI.Maptor).
